# PassSafe Backend API

Express + MongoDB backend for the PassSafe password manager.

## Features
- REST API for storing and retrieving passwords
- Modular, production-ready code
- CORS enabled for frontend integration
- Environment variable support via dotenv

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
   The server will run on `http://localhost:5000` by default.
