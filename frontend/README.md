# PassSafe Frontend (UI Only)

A modern, responsive password manager UI built with React and Vite.

## Features
- Add passwords with labels
- See password strength (placeholder, API integration coming)
- View saved passwords (mock data for now)
- Responsive, stylish, and centered design

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:5173](http://localhost:5173) in your browser.
